Приложения Telegram (MTProto)

У каждого пользователя свой секрет и личная страница с QR-кодом. Адрес страницы можно отправить человеку.

Боты (Bot API через шлюз)

Как подключить Telegram вручную
  1. Telegram Desktop: Настройки → Продвинутые настройки → Тип подключения → Прокси → Добавить прокси → MTProto.
  2. Android / iOS: Настройки → Данные и память → Прокси → Добавить прокси → MTProto. Проще всего открыть на телефоне личную страницу пользователя и нажать «Открыть в Telegram».
  3. Сервер, порт и секрет есть на личной странице пользователя: вкладка «Пользователи» → «QR и ссылка».

Не грузятся фото и видео? Оставьте в «DC → IP» только 4:149.154.167.220 или очистите поле (вкладка «Настройки»).

Если в логах ошибки подключения по IPv6, выключите в настройках прокси Telegram «Попытка соединения через IPv6».

Пользователи MTProto

Лимит: 0 — пользователь выключен, N — до N одновременных подключений. Одно приложение Telegram держит несколько подключений (основное и отдельные для загрузки медиа), поэтому ставьте с запасом, например 10–20 на устройство; пик виден в отчёте.

У пользователей с доступом снаружи в ссылке стоит адрес этой страницы. Если снаружи он недоступен, укажите «Внешний адрес в ссылках» в настройках.

Датацентры Telegram (DC → IP)

Cloudflare Proxy

Одно HTTP/2-соединение на датацентр и домен для всех загрузок медиа. Нужны CF-прокси и TLS.

Cloudflare Worker

Доступ

Ключевые слова: loopback (этот компьютер), lan (частные подсети интерфейсов этой машины, публичные не входят), private (все частные адреса), any (все адреса, пароль не спрашивается никогда). Также CIDR и отдельные IP.
